# 共创意向提案草稿

状态：未提交，未获得官方合作确认。项目公开后补入真实仓库及 Release 链接，再由项目发起者决定向原作者提交。

**建议主题：ESP-SparkBot“小白”三合一固件成果分享与社区共创意向**

ESP-Friends / ESP-SparkBot 维护者，你们好：

我是一名喜欢自己动手做硬件、也很在意实际交互体验的使用者。感谢你们把 ESP-SparkBot 开源，让我能从一台小机器人开始，一边体验、一边提出问题和改进想法。

我希望小白能在同一个固件里聊天、开坦克、看摄像头，闲下来还能玩木鱼、骰子和小游戏，于是基于小智与 ESP-SparkBot 的开源资料，借助 AI 辅助开发，整理了“小白”整合固件和手机控制端。

目前已整理的成果包括：

1. 小智对话与履带底座遥控在同一固件使用；本地网页支持横竖屏、相机画面和急停。
2. 白色/机甲双眼，方向触碰表情、摸头和揉脸反馈，字幕与音量设置。
3. 木鱼、骰子、2048、时钟及三航道海上航行游戏。
4. Android 同网发现设备，手机形象配色与名称在机器人上共享保存。
5. 可下载固件、源码、刷写说明、校验值和明确区分的自动测试/实物反馈记录。

我比较想继续做好的是普通使用者能直接感受到的部分：少刷几次机、手机拿着顺手、触摸有回应、出了问题能复现。也希望保留上游署名和完整来源，把可复用的改进反馈回社区。

想请教维护者：这类成果更适合以独立 example、社区展示链接，还是拆分通用改进 PR 的方式参与？如果方向合适，我愿意进一步讨论共同完善的范围。具体维护安排、资源支持及公开署名方式希望在沟通后再确认。

我没有把 Factory 所有独立示例完整移植，也没有做“130% 硬件超频”等未经验证的宣传。当前版本的已知边界和测试范围会公开说明。

感谢你们的开源工作，期待听听建议。
